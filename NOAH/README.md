NOAH – Station README
Zweck
NOAH ist eine zentrale Station innerhalb von SHOW.live, die mehrere Kernmodule verbindet:
SLI‑Darstellung, Continuum‑Flow, Vector‑Energie und die interne Brücke zwischen ON3‑Systemen.

Module
NOAH.js – Hauptmotor der Station

SLI.js – Darstellungsschicht für Formen, Axiome und Flächen

brücke.js – Verbindungsmodul zwischen NOAH und anderen Stationen

continuum-bridge.js – Zeit‑Raum‑Flow zwischen Stationen

vector.energie.js – Energie‑Vektor für Bewegungen und Werte

ID.html – Identitätsoberfläche

index.html – Startpunkt der Station

Flow
NOAH.js lädt SLI.js

brücke.js verbindet NOAH mit Continuum

continuum-bridge.js erzeugt den Zeit‑Raum‑Flow

vector.energie.js liefert Energie‑Vektoren

index.html zeigt die Station in SHOW.live

Verbindung zu ON3
NOAH nutzt ON3 als Engine‑Layer:

ON3 liefert Quadrisierung

ON3 liefert Vektorisierung

ON3 liefert Mind‑Flow

NOAH bindet diese Werte in SLI und Continuum

Verbindung zu SHOW.live
SHOW.live lädt NOAH als Station:

Darstellung über SLI

Flow über Continuum

Energie über Vector

UI über ID.html
